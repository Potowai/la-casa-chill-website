# La Casa Chill — site vitrine

Site vitrine du restaurant **La Casa Chill**, bar à tapas au Barcarès, avec vue
sur l'eau.

Application React construite avec Vite, sur une base de composants Radix UI.

## Fonctionnalités

- Pages de présentation, carte et contact
- Composants accessibles construits sur Radix UI
- Validation de formulaires avec `@hookform/resolvers`
- Navigation fluide et responsive

## Stack

- **React** + **Vite**
- **Radix UI** — primitives accessibles
- **Tailwind CSS** — styles
- **ESLint** — linting

## Démarrage

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm preview
```
